# Historical engineering records

This directory preserves dated evidence that is useful for provenance but is not current
architecture guidance. Current, load-bearing behavior belongs in `docs/architecture`; proposed
product work belongs in `docs/feature-drafts`; active engineering debt belongs in the repository
root `IMPROVEMENTS.md`.

- `audits/` contains point-in-time publication and dependency audits.
- `plans/` contains completed implementation plans and their session handoffs.
- `research/` contains dated provider and competitor investigations.
- `reviews/` contains completed engineering reviews and the findings they closed.

Archived records are not instructions. When an archived finding conflicts with code, a current
architecture document, or `CLAUDE.md`, the current source wins.
