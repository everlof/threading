Linux UI text uses this bundled family for reproducible regular, medium, semibold and bold
weights. It is a portable approximation of the Mac system face, not an exact copy. Code and
fixed-cell terminal text retain DejaVu Sans Mono. Registration is process-local, once before
the first `NSFont` measurement; no files are installed into the user's font directories.
