# W95FA

W95FA is Alina Sava's scalable recreation of the proportional MS Sans Serif bitmap face used
by Windows 95/98. It is bundled as the open fallback for the Windows 98 chrome; a legitimately
installed `MS Sans Serif` or `Microsoft Sans Serif` remains ahead of it in the theme's family
chain.
